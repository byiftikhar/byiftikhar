### Featured project

<a href="https://github.com/byiftikhar/telescope-inspector">
    <img src="https://raw.githubusercontent.com/byiftikhar/telescope-inspector/main/.github/assets/banner.png" alt="Telescope Inspector: a fast, searchable viewer for Laravel Telescope" width="100%">

**[Telescope Inspector](https://github.com/byiftikhar/telescope-inspector)** - a fast, searchable viewer for
Laravel Telescope. Search, filter and prune requests, jobs, queries and logs without the page freezing on big
requests. Light and dark theme, MIT licensed.

```bash
composer require byiftikhar/telescope-inspector --dev
```
